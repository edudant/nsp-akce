# Katalog písní NSP pro import

Zdroj: uživatelem dodaný soubor „Dudácká NSP.docx“ (28. 9. 2026), vyčištěný
podle následného upřesnění uživatele. Nejde zatím o importovaný katalog aplikace.

Z 59 neprázdných položek přílohy vzniká 57 položek písní a dvě kategorie.
Kombinace s lomítkem se zachovávají jako jedna položka. Importují se pouze
názvy bez poznámek a značek; nářeční znění se automaticky neopravuje.
